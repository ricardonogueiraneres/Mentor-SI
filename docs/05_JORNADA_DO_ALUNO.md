# Mentor SI
# Jornada do Aluno

Versão: 1.0

---

# Objetivo

Definir toda a experiência do aluno dentro do Mentor SI, desde o primeiro acesso até sua entrada no mercado de trabalho.

A prioridade da plataforma é oferecer uma jornada organizada, personalizada e motivadora.

---

# Etapa 1 — Cadastro

O aluno cria sua conta.

Informações iniciais:

- Nome
- E-mail
- Senha
- Foto (opcional)

Após o cadastro, o aluno acessa sua área pessoal.

---

# Etapa 2 — Teste de Nivelamento

Antes de iniciar os estudos, o aluno realiza um pequeno teste para identificar seu nível de conhecimento.

Níveis possíveis:

- Iniciante
- Básico
- Intermediário
- Avançado

A Inteligência Artificial utiliza esse resultado para montar um plano de estudos personalizado.

---

# Etapa 3 — Plano de Estudos

A IA cria automaticamente uma trilha baseada em:

- Objetivo profissional
- Conhecimento atual
- Tempo disponível para estudar
- Área de interesse

Exemplos:

- Python
- Desenvolvimento Web
- Inteligência Artificial
- Banco de Dados
- Redes
- Segurança
- Ciência de Dados

---

# Etapa 4 — Primeira Aula

Cada módulo possui:

- Videoaula
- Material escrito
- Exemplos
- Código
- Explicações da IA

Ao final da aula o aluno pode conversar com o Mentor IA para tirar dúvidas.

---

# Etapa 5 — Exercícios

Após cada aula:

- Exercícios básicos
- Exercícios intermediários
- Desafios

O aluno pode solicitar dicas ao Mentor IA.

---

# Etapa 6 — Quiz

Ao finalizar um módulo:

- Questões objetivas
- Questões práticas
- Correção imediata
- Feedback personalizado

---

# Etapa 7 — Projeto Prático

Todo módulo gera um projeto.

Exemplos:

- Calculadora
- Sistema de Login
- API
- Dashboard
- Chatbot
- Site

A IA acompanha o desenvolvimento.

---

# Etapa 8 — Correção Inteligente

O Avaliador IA analisa:

- Organização
- Lógica
- Código
- Boas práticas
- Possíveis melhorias

O aluno recebe um relatório completo.

---

# Etapa 9 — XP e Conquistas

Ao concluir atividades o aluno recebe:

- XP
- Medalhas
- Conquistas
- Sequência de estudos (Streak)

Esses dados aparecem no Dashboard.

---

# Etapa 10 — Portfólio

Os projetos aprovados podem ser publicados automaticamente no Portfólio Mentor SI.

Cada projeto apresenta:

- Descrição
- Tecnologias utilizadas
- Capturas de tela
- Link do GitHub
- Demonstração (quando disponível)

---

# Etapa 11 — Currículo

A plataforma ajuda o aluno a criar um currículo profissional.

Informações incluídas:

- Projetos
- Competências
- Certificados
- Portfólio

---

# Etapa 12 — LinkedIn

O Mentor SI oferece sugestões para:

- Melhorar o perfil
- Criar publicações
- Destacar projetos
- Preparar networking

---

# Etapa 13 — Simulação de Entrevista

O aluno realiza entrevistas simuladas com IA.

A IA avalia:

- Comunicação
- Conhecimento técnico
- Resolução de problemas
- Postura profissional

Ao final, fornece um relatório com pontos fortes e oportunidades de melhoria.

---

# Etapa 14 — Empresas Parceiras

Empresas poderão acessar perfis públicos dos alunos.

Cada perfil apresentará:

- Projetos
- Trilhas concluídas
- XP
- Certificados
- Competências
- GitHub
- LinkedIn

---

# Etapa 15 — Primeiro Emprego

Objetivo final da jornada.

Quando o aluno conquistar uma oportunidade profissional, ele poderá registrar essa conquista na plataforma.

Esse indicador será utilizado para medir o impacto do Mentor SI.

---

# Evolução Contínua

Mesmo após conseguir emprego, o aluno continuará utilizando o Mentor SI para:

- Novas trilhas
- Especializações
- Certificações
- Atualizações tecnológicas
- Evolução profissional

---

# Nossa Filosofia

O aluno nunca estará sozinho.

Sempre haverá uma Inteligência Artificial disponível para ensinar, orientar, motivar e acompanhar sua evolução.
