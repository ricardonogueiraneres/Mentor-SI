# Mentor SI
# Arquitetura da Plataforma

Versão: 1.0

---

# Objetivo

Definir a estrutura visual e funcional da plataforma Mentor SI.

Cada módulo deverá ser independente, mas totalmente integrado aos demais.

---

# Estrutura Geral

A plataforma será dividida em módulos.

## Dashboard

Será a tela principal.

Mostrará:

- Boas-vindas
- Progresso geral
- XP
- Sequência de estudos
- Cursos em andamento
- Próxima atividade
- Últimas conquistas

---

## Área de Estudos

Responsável pelas trilhas.

Cada trilha possuirá:

- módulos
- aulas
- exercícios
- quizzes
- projetos

---

## Mentor IA

Professor virtual.

Funções:

- explicar conteúdos
- responder dúvidas
- criar exercícios
- sugerir desafios
- recomendar materiais

---

## Avaliador IA

Analisa projetos enviados.

Avalia:

- organização
- lógica
- qualidade
- documentação
- boas práticas

Gera relatório completo.

---

## Dashboard de Desempenho

Mostra:

- evolução
- tempo estudado
- XP
- gráficos
- pontos fortes
- pontos a melhorar

---

## Sistema de XP

Cada ação gera experiência.

Exemplos:

- concluir aula
- resolver exercício
- concluir projeto
- responder quiz
- acessar diariamente

---

## Perfil

Cada aluno possuirá:

- foto
- biografia
- nível
- XP
- certificados
- projetos
- GitHub
- LinkedIn

---

## Portfólio

Lista automaticamente:

- projetos
- certificados
- tecnologias
- demonstrações
- repositórios

---

## Empresas

Área exclusiva.

Permite:

- publicar vagas
- procurar alunos
- visualizar perfis
- entrar em contato

---

## Configurações

O aluno poderá alterar:

- dados pessoais
- senha
- foto
- notificações
- tema
- preferências

# Filosofia

Toda funcionalidade da plataforma deve contribuir para o crescimento profissional do aluno.

A tecnologia existe para facilitar o aprendizado e aproximar pessoas de oportunidades reais.
