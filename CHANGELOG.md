# Changelog

Este arquivo registra todas as mudanças importantes do projeto Mentor SI.

O projeto segue o padrão **Keep a Changelog** e utiliza versionamento semântico para documentar sua evolução.

## [6.0] - 2026-07-22

### ✨ Adicionado

- Sistema de cadastro de usuário.
- Sistema de XP e níveis.
- Sistema de sequência diária de estudos (Streak).
- Sistema de conquistas.
- Sistema de missões.
- Quiz de Python com persistência de resultados.
- Dashboard do aluno.
- Histórico de quizzes.
- Estatísticas de desempenho.
- Plano de estudos personalizado.
- Sistema de recomendações.
- Relatórios de progresso.
- Persistência de dados utilizando SQLite.
- Arquitetura modular baseada em repositório.
- Documentação do projeto (`README.md` e `CHANGELOG.md`).

### 🔄 Alterado

- Refatoração completa da arquitetura do projeto.
- Organização do código em módulos independentes.
- Inclusão de type hints em todas as funções.
- Inclusão de docstrings em todos os módulos.
- Padronização dos nomes de funções e constantes.
- Melhoria da legibilidade e manutenção do código.

### 🐛 Corrigido

- Correções na persistência de dados.
- Ajustes na atualização do sistema de Streak.
- Correções no cálculo de XP.
- Melhorias no fluxo dos quizzes.
- Ajustes na geração do plano de estudos.
- Correções gerais de organização e estrutura do projeto.
